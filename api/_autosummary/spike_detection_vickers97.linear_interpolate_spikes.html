spike_detection_vickers97.linear_interpolate_spikes

spike_detection_vickers97.linear_interpolate_spikes(data: ndarray, is_spike: ndarray, error_value: float | None = None) → ndarray[source]

Replace spikes with linear interpolation using neighboring valid values. Started form a python conversion of the EDDYPRO Fortran spike detection algorithm, based on Vickers and Mahrt (1997) spike detection method. Subsequently modified by Bernard Heinesch and Jonathan Bitton

Parameters:

datanp.ndarray

Input data array

is_spikenp.ndarray

Boolean array indicating spike locations

error_valuefloat

Value indicating invalid/error data

Returns:

np.ndarray

Data array with spikes replaced by linear interpolation
